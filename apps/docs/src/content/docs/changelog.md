## 2026-10 · Platform groundwork (in progress)

Being built and rolled out this month:

- **Docs** at docs.windle.fun: concepts, guides, early API notes, brand kit, draft legal pages.
- **Sign-In With Solana** on oauth.windle.fun, with one session shared across windle subdomains. Email, X and Google
  sign-in exist in code but are disabled.
- **API** at api.windle.fun: health checks, SIWS auth, session and `/v1/me` endpoints. Early and unstable; see the
  [reference](https://api.windle.fun/reference).
- **Product app** at app.windle.fun: sign-in gate, account page and an empty "My promises" dashboard.
- **Landing page** at www.windle.fun with an interactive, local-only demo market (no chain, no funds).
